# Контрольные вопросы

### 1. Чем обращение obj.key отличается от obj[key]?

`obj.key` — обращение к свойству по имени `key`.

`obj[key]` — обращение к свойству, имя которого хранится в переменной `key`.

### 2. Как определяется значение this при вызове метода? Почему this теряется при передаче метода в переменную?

`this` зависит от способа вызова функции.

При вызове `obj.method()` значение `this` — объект `obj`.

При передаче метода в отдельную переменную связь с объектом теряется, поэтому `this` больше не ссылается на исходный объект.

### 3. Чем this в стрелочной функции отличается от this в обычной?

В обычной функции `this` определяется способом её вызова.

Стрелочная функция не имеет собственного `this`, а берёт его из внешней области видимости.

### 4. Что такое поверхностная копия? Почему изменение вложенного объекта в копии видно в оригинале?

Поверхностная копия копирует только первый уровень объекта.

Вложенные объекты не копируются, а остаются общими ссылками. Поэтому изменение вложенного объекта видно и в оригинале.

### 5. Почему два объекта с одинаковым содержимым не равны по ===?

Потому что объекты сравниваются по ссылке, а не по содержимому.

### 6. Какие четыре шага выполняет оператор new?

1. Создаёт новый пустой объект.
2. Связывает его с прототипом конструктора.
3. Вызывает конструктор с `this`, указывающим на новый объект.
4. Возвращает созданный объект, если конструктор явно не вернул другой объект.

### 7. Что такое прототип и как движок ищет свойство по цепочке прототипов?

Прототип — это объект, от которого другой объект может наследовать свойства и методы.

Сначала JavaScript ищет свойство в самом объекте. Если не находит, проверяет его прототип, затем следующий и так далее, пока не дойдёт до `null`.

### 8. Чем отличаются call, apply и bind?

Все три метода позволяют управлять значением `this`.

- `call` вызывает функцию сразу и передаёт аргументы через запятую.
- `apply` вызывает функцию сразу, но передаёт аргументы массивом.
- `bind` создаёт новую функцию с привязанным `this`, но не вызывает её сразу.

### 9. Какие флаги есть у свойства и что делает каждый из них?

- `writable` — разрешает или запрещает изменение значения свойства.
- `enumerable` — определяет, будет ли свойство участвовать в перечислении, например через `for...in`.
- `configurable` — разрешает или запрещает удаление свойства и изменение его дескриптора.

### 10. Чем Object.freeze отличается от const? Почему заморозка поверхностная?

`const` запрещает повторное присваивание переменной, но позволяет изменять содержимое объекта.

`Object.freeze()` запрещает изменять, добавлять и удалять свойства объекта.

Заморозка поверхностная, потому что защищает только сам объект, но не вложенные в него объекты.
