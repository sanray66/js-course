# Вопросы по JavaScript

## Задание 7. IIFE-модуль

**От чего защищает IIFE**

- Не засоряет глобальную область видимости — снаружи доступна только переменная CartModule.

- Защищает внутренние переменные (items) от прямого изменения извне.

- Снижает риск конфликтов имён с переменными из других частей программы.
