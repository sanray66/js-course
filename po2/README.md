# Вопросы по JavaScript

## Задание 7. IIFE-модуль

**От чего защищает IIFE**

- Не засоряет глобальную область видимости — снаружи доступна только переменная CartModule.

- Защищает внутренние переменные (items) от прямого изменения извне.

- Снижает риск конфликтов имён с переменными из других частей программы.

# Контрольные вопросы

### 1. Чем Function Declaration отличается от Function Expression?

Function Declaration — обычное объявление функции через `function`. Её можно вызвать до места объявления.

Function Expression — функция, которая создаётся как выражение и обычно записывается в переменную. Её нельзя вызвать до выполнения строки объявления переменной.

### 2. Что получит параметр, если аргумент не передан? Когда срабатывает значение по умолчанию?

Если аргумент не передан, параметр получает `undefined`.

Значение по умолчанию срабатывает, когда аргумент не передан или передан `undefined`.

### 3. Чем вывод значения через console.log отличается от возврата через return?

`console.log()` выводит значение в консоль, но не возвращает его из функции.

`return` возвращает значение из функции, чтобы его можно было сохранить в переменную или использовать дальше.

### 4. Почему () => { name: 'x' } возвращает undefined?

Потому что фигурные скобки воспринимаются как тело функции, а не как объект. Внутри нет `return`.

Чтобы вернуть объект, нужно обернуть его в круглые скобки:

`const getObject = () => ({ name: 'x' });`

### 5. Что такое лексическое окружение и цепочка областей видимости?

Лексическое окружение — место, где хранятся переменные и ссылки на внешнее окружение.

Цепочка областей видимости позволяет функции искать переменные сначала в своей области видимости, а затем во внешних.

### 6. Что такое замыкание? Почему переменная count не исчезает после завершения createCounter?

Замыкание — это функция вместе с доступом к переменным из внешней области видимости.

Переменная `count` не исчезает, потому что внутренняя функция продолжает ссылаться на неё и использовать её после завершения `createCounter`.

### 7. Зачем нужны внешние скобки в IIFE?

Внешние скобки превращают объявление функции в функциональное выражение, которое можно сразу вызвать.

IIFE позволяет создать отдельную область видимости и не засорять глобальную область переменными.

### 8. Что такое стек вызовов и почему рекурсия без базового случая вызывает RangeError?

Стек вызовов — структура, в которой хранятся вызовы функций, ожидающие завершения.

Без базового случая рекурсия вызывает саму себя бесконечно, стек переполняется и возникает ошибка `RangeError: Maximum call stack size exceeded`.

### 9. Почему функцию, объявленную через function, можно вызвать до объявления, а через const нельзя?

Function Declaration полностью всплывает благодаря hoisting, поэтому её можно вызвать до объявления.

Переменная `const` также учитывается при hoisting, но до выполнения строки объявления находится во временной мёртвой зоне (TDZ). Поэтому обратиться к ней раньше нельзя.

### 10. Почему изменение поля объекта внутри функции видно снаружи, а присваивание параметру нового объекта нет?

При передаче объекта в функцию копируется ссылка на него. Поэтому изменение его свойства влияет на исходный объект.

Если присвоить параметру новый объект, изменится только локальная переменная параметра, а исходный объект останется прежним.
