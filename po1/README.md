## Задание 5. Преобразования

**Объясните результат выражений "5" + 3, "5" - 3, [] + {}, null == undefined.**

- "5" + 3 = "53" - оператор + при наличии строки склеивает строки.
- "5" - 3 = 2 - оператор - не умеет склеивать строки, поэтому JS преобразует "5" в число.
- [] + {} = [object Object] - [] приобразуется в строку из-за +, {} если пусток то становится [object Object].
- null == undefined = True - В JS при нестрогом сравнении == значения null и undefined считаются равными друг другу.







## Контрольные вопросы

### 1. Чем let отличается от const? Что именно запрещает const?

let позволяет повторно присваивать переменной новое значение, а const запрещает повторное присваивание.

### 2. Почему typeof null возвращает "object"?

Это историческая особенность JS, которая сохранилась для обратной совместимости. На самом деле null обозначает отсутствие значения, а не объект.

### 3. Почему 0.1 + 0.2 !== 0.3 и как правильно хранить деньги?

Некоторые десятичные дроби невозможно точно представить в двоичной системе счисления, поэтому возникают небольшие погрешности вычислений. Для хранения денег обычно используют целые числа в минимальных денежных единицах, например копейках, или специальные библиотеки для точной работы с десятичными числами.

### 4. Какие значения в JavaScript считаются ложными?

Ложными (falsy) являются:

- false
- 0
- -0
- 0n
- ""
- null
- undefined
- NaN

### 5. Что вернёт выражение '' || 'нет' и выражение '' ?? 'нет'? Почему?

'' || 'нет' вернёт 'нет', потому что оператор || возвращает правое значение, если левое ложное.

'' ?? 'нет' вернёт пустую строку, потому что оператор ?? проверяет только null и undefined.

### 6. Чем Number('12px') отличается от parseInt('12px')?

Number('12px') вернёт NaN, потому что вся строка не является корректным числом.

parseInt('12px') вернёт 12, потому что функция считывает целое число в начале строки.

### 7. Почему после const b = a изменение массива b видно в a?

Потому что обе переменные ссылаются на один и тот же массив в памяти. Изменение массива через одну переменную видно и через другую.

### 8. Что будет в switch, если забыть break?

Выполнение продолжится в следующих блоках case

### 9. Чем while отличается от do...while?

while сначала проверяет условие, а затем выполняет тело цикла. Поэтому цикл может не выполниться ни разу.

do...while сначала выполняет тело цикла, а затем проверяет условие. Поэтому он выполнится минимум один раз.

### 10. Что показывают панели Scope, Watch и Call Stack в отладчике?

**Scope** — показывает переменные и их значения в текущей области видимости.

**Watch** — позволяет отслеживать значения выбранных переменных и выражений.

**Call Stack** — показывает последовательность вызовов функций, которая привела к текущей точке выполнения программы.
