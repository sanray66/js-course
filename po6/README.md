Контрольные вопросы
1. Что выполнится раньше: return внутри try или код в finally? Почему?

Раньше выполнится код в finally.

return сначала вычисляет значение, но функция отдаёт его только после finally. Поэтому finally выполняется всегда.

2. Почему try..catch не перехватывает синтаксическую ошибку в самом файле скрипта?

Перед выполнением движок разбирает весь файл целиком. Синтаксическая ошибка находится на этом этапе, и try ещё не начал работать.

try..catch ловит только ошибки времени выполнения.

3. Зачем создавать собственные классы ошибок вместо new Error(текст)?
Тип ошибки можно проверить через instanceof.
В ошибку можно добавить свои поля (field, productId и т.д.).
Не нужно проверять ошибку по тексту сообщения.
4. Как читать стек вызовов в err.stack? Что такое раскрутка стека?

Стек читается сверху вниз: первая строка показывает, где сломалось, следующие — как туда попали.

Раскрутка стека — после throw движок выходит из функций одну за другой, пока не найдёт try..catch. Код после вызова в этих функциях не выполняется.

5. Что такое изоморфная обработка ошибок и чем «ошибка как значение» отличается от исключения?

Изоморфная обработка — код одинаково работает в разных окружениях (браузер, Node.js).

Функция не выбрасывает исключение, а возвращает ошибку в результате, например [err, result]. Такую ошибку видно в коде, а исключение «прыгает» по стеку и может остаться незамеченным.

6. Почему в new Date(2026, 8, 1) получается сентябрь? Что хранит объект Date внутри?

Месяцы нумеруются с нуля: 0 — январь, 8 — сентябрь.

Внутри Date хранит одно число — миллисекунды с 1 января 1970 года (UTC).

7. Почему (1.005).toFixed(2) равно '1.00' и как правильно округлять деньги?

Число 1.005 хранится неточно, как 1.00499999999999989, и округляется вниз.

Деньги нужно хранить в целых копейках, а в рубли переводить только при выводе.

8. Чем свойство-символ отличается от обычного свойства объекта?

Свойство-символ не видно в Object.keys, for..in и JSON.stringify.

Получить его можно только по самому символу. Каждый символ уникален, поэтому ключи не пересекаются.

9. Как устроен протокол итерации и что делает yield в генераторе?

У объекта есть метод Symbol.iterator, который возвращает итератор с методом next(). Он отдаёт { value, done }.

yield приостанавливает генератор и отдаёт значение. Следующий next() продолжает с того же места.

10. Почему WeakMap и WeakSet нельзя перебрать и для чего они нужны?

Сборщик мусора может удалить объект в любой момент, поэтому перебор давал бы разный результат.

WeakSet нужен для отметок («заказ обработан»), WeakMap — для кеша и данных, привязанных к объекту, без утечек памяти.

Вопросы из самостоятельных заданий
Почему Map лучше объекта для ключей-чисел?

В объекте ключи становятся строками (1 и '1' — один ключ). В Map ключи хранятся как есть.

Зачем WeakMap нужен для кеша данных по DOM-элементам?

Обычная Map держит элемент в памяти вечно (утечка). WeakMap удаляет данные вместе с элементом.

Почему state.items.push(...) не вызывает перерисовку и как это исправить?

Proxy видит только запись свойства items, а push меняет массив внутри. Исправление: присвоить новый массив — state.items = [...state.items, item].
